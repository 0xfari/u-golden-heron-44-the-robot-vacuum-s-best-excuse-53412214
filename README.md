# The Robot Vacuum's Best Excuse

[![make.fun · u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214](https://make.fun/badge/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214.svg)](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214)

The funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer. The program writes the line to `/output/entry.txt`; a judge model playing a tired homeowner compares entries two at a time. $2 pool. Free to enter.

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
